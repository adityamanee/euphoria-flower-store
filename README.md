# Handmade Flower Store — React/Vite

A warm, playful ecommerce storefront for handmade pipe-cleaner flowers.

## Included in this version
- Larger cropped handmade-flower logo in the header and footer
- No separate brand-name text beside the logo
- Local product photography from the user's uploaded images
- Product-specific imagery for roses, sunflowers, mini bouquets, tulips, pastel sets, gift bouquets and custom bouquets
- Flower Keychain added as a product and category
- Previous Tiny Desk Flower removed
- Cart now displays the actual product image when available
- Our Story page and Instagram link
- Responsive layout, cart, checkout, payment and order confirmation flow

## Run locally
```bash
npm install
npm run dev
```

## Images
All newly supplied product photos are stored locally under `public/images/`.
The logo is stored as `public/logo.png`; the original un-cropped logo is retained as `public/logo-original.png`.
